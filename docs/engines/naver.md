# Naver (CUE: / AI 브리핑) — 치과 추천 로직

**한 줄:** 로컬 치과 추천의 진짜 엔진은 여전히 **플레이스(Smart Place) + 블로그/리뷰 + 지도**. CUE:/AI 브리핑은 그 위에서 같은 **네이버 내부 코퍼스**를 RAG로 요약하는 새 레이어. 외부 AI 크롤러는 차단 → 별도 월드.

## 추천 생성 로직
내부-코퍼스-우선 하이브리드 RAG. (1) **클래식 로컬 = 플레이스 DB 회수·랭킹 + 블로그/카페/지식인(C-rank/D.I.A.)** — 1차 엔진. (2) **CUE:** HyperCLOVA X로 추론+검색계획+도구+RAG(통합검색·뉴스·쇼핑·플레이스 등)→요약. (3) **AI 브리핑** = 통합검색 상단의 조건부 트리거 RAG 요약: AiRSearch가 질의 유형(정보/내비/거래) 분류 → 일부 정보형만 트리거 → 네이버 내부 블로그/카페/지식인/플레이스 우선 합성. **열린 웹 RAG가 아닌 월드가든 회수**(외부 AI 크롤러 차단이 내부 콘텐츠 가치를 높임).

## 추천을 만드는 신호 (플레이스 가중은 **실무 추정** — 네이버 공식 스펙 미공개)
- **플레이스 적합도(상호·카테고리·대표키워드·주소)** [high] — 상호가 가장 큰 비중(추정). 회수의 1차 게이트.
- **플레이스 인기도(실유입·체류·예약·저장·전화·길찾기·리뷰)** [high] — 2025 알고리즘이 원수치보다 **자연 유입 비율·재방문/체류**로 이동(단일 SEO 블로그 출처, 추정).
- **신뢰도/어뷰즈 방지** [high] — 트래픽/리뷰 구매·허위정보 시 패널티·delisting. (※ "1000/일 키워드에 2000 유입=비정상" 같은 단정 수치는 출처 없어 **예시로만**.)
- **블로그/카페 리뷰 + C-rank** [high] — AI 브리핑 소스 선택에도 기여(C-rank=출처 신뢰). 미편집 AI 텍스트는 필터.
- **엔티티/E-E-A-T(전문의·수련·논문, LocalBusiness/FAQPage JSON-LD)** [medium], **AEO 구조 적합(소제목 2~7·리스트·answer-first)** [medium], **거리/위치** [low, 추정].

## 인용 메커니즘
- **클래식 = 결과가 곧 인용**(플레이스/블로그/카페/지식인 링크). **Local Open API**(`openapi.naver.com/v1/search/local.json`, Client-Id/Secret 필요)는 `items[].{title,link,category,address,roadAddress,mapx,mapy}` 반환.
- **AI 브리핑/CUE: = 합성 요약 + 출처 카드/배지.** 인용 소스를 노출하는 **공개 API 필드 없음** — 렌더된 SERP의 링크/배지를 **수동 확인**.

## 측정 가능성 — **checklist** (API 없음)
- **클래식 부분 자동:** Local Open API는 구조화 place를 주지만 **display 최대 5, start=1 고정, sort=random|comment** → 얇은 프록시이고 **실제 플레이스 SERP 순서를 재현 못 함.**
- **AI 브리핑/CUE: 자동 불가:** 출력/소스 개발자 엔드포인트 없음 → "거래처 인용됐나"는 **수동(질의 → 브리핑·배지 육안 확인)**. SERP 스크래핑은 ToS/봇차단.

## 최적화 레버
1. **플레이스 정합성/완성도**(상호·카테고리=치과·대표키워드·주소·시간·진료과목·사진, 홈피와 일치). 2. **실사용 행동 신호 유도**(자연 방문자리뷰·네이버예약·저장·길찾기, 키워드 검색량 비례 자연속도 — **트래픽/리뷰 구매 금지, 스파이크 억제·delisting 위험**). 3. **경험 기반 블로그/카페 후기**로 C-rank↑(미편집 AI 금지). 4. **엔티티/E-E-A-T + LocalBusiness/FAQPage/Article JSON-LD + answer-first 20~30 Q&A**. 5. **AEO 포맷**(소제목 2~7·리스트·날짜). 6. **지식인 Q&A 등장**.

## 한국/치과 특이사항
- 치과는 **YMYL + 의료광고 규제** → AI 레이어가 보수적. AI 브리핑은 정보/인과형(예: 두통 원인)에 트리거되고, **상업적 "추천/비교" 질의(예: "강남 치과 추천")엔 트리거 안 한다고 보도**(SEO 분석, 공식 아님) → 고의도 치과 상업 검색은 **플레이스+블로그+지도 스택이 진짜 엔진.**
- **외부 AI 크롤러 차단:** blog.naver.com robots가 GPTBot·OAI-SearchBot·PerplexityBot·ClaudeBot·Google-Extended·CCBot 등 **AI 학습/RAG 접근 금지** → 네이버 내부 콘텐츠는 ChatGPT/Perplexity/Claude에 **안 보임**. ∴ **네이버 최적화 ≠ 외부 AI 최적화(별도 스코어카드).**
- **네이버 메이트 / 'AI 브리핑 인용수'**: 인용 크리에이터 배지 + 지원 프로그램은 **공식 실재(언론 검증)** — 단 "2026-01부터 집계" 시작일은 단일(Threads) 출처.
- 의료광고법(제56조): 최상급/전후/유인 표현 회피 → 리뷰/키워드 과열 전술 제약.
