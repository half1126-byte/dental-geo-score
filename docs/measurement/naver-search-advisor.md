# 네이버 — 서치어드바이저 + 스마트플레이스 통계 (1차, 한국)

**무엇:** 한국 치과 발견의 핵심은 네이버. 네이버가 주는 공식 1차 통계 두 개 + AI 레이어 신호 하나.

## 1) 네이버 서치어드바이저 (Search Advisor)
- 네이버판 Search Console. 사이트의 **네이버 검색 노출/클릭, 색인 현황, 사이트 최적화 진단** 제공.
- 적용: 거래처 사이트가 네이버에 잘 색인·노출되는지의 1차 신호.

## 2) 스마트플레이스 통계 (Smart Place)
- 플레이스의 **조회수·유입 키워드·전화·길찾기·예약·리뷰** 통계.
- = 네이버 로컬(플레이스) 추천 레이어의 행동 1차 데이터. → [docs/engines/naver.md](../engines/naver.md)의 플레이스 게임과 직결.

## 3) 'AI 브리핑 인용수' (네이버 메이트)
- 네이버가 블로그별 **AI 브리핑 인용수**를 집계해 크리에이터(메이트) 프로그램에 반영(언론 검증). = 네이버 자체 1차 AI-인용 신호.
- ⚠️ **공개 대시보드/공용 측정 도구가 아님**(크리에이터 한정). 일반 거래처가 직접 당기는 API 아님.

## 한계 / 측정 (POC 확정 2026-06-23)
- ❌ **API 없음(확정).** 네이버 Open API 카탈로그에 Search Advisor/Smart Place/AI브리핑 **엔드포인트 없음** → 전부 **수동 UI 로그인·Excel export**(~90일 윈도, 놓치면 영구 손실). 인접 공식: **DataLab**(검색 상대추세만·사이트/플레이스별 아님)·**검색광고 API**(유료광고·광고주별). 스크래핑=ToS/계정 위험.
- AI 브리핑/CUE: 출력·소스 공개 API 없음 → 육안.
- **외부 AI 크롤러 차단**으로 네이버 내부 신호는 ChatGPT/Perplexity/Claude와 분리(별도 스코어카드).
