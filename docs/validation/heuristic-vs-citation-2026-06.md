# 검증 연구 v0.1 — 휴리스틱 점수 vs 실제 AI 인용 (2026-06)

## 요약 (결론 먼저)

치과 홈페이지 **휴리스틱 GEO 점수(0~100)는 실제 ChatGPT 인용/노출을 예측하지 못한다.**
통제된 실측(같은 질의 "성남치과 추천", 같은 지역=성남)에 점수를 오버레이한 결과 **세 가지가 동시에 깨졌다**:

1. **역상관/무상관** — 안 뜬 1곳이 최고점(63), 뜬 곳들은 60·15~45·측정불가.
2. **측정불가 2/5** — GPT가 인용한 치과의 40%를 우리 도구가 아예 못 읽음(TLS 차단·인증서 만료).
3. **불안정(재현성 없음)** — 같은 사이트 재측정 시 15 ↔ 45.

→ 점수는 제품의 1급 지표가 될 수 없다. **실측(실제 엔진 인용 측정)이 중심, 점수는 보조(페이지 위생).**
이 문서가 "실측이 중점" 결정의 근거이며, [redesign-realmeasurement-first.md](../redesign-realmeasurement-first.md)로 이어진다.

## 방법

- **그라운드 트루스:** 실제 ChatGPT 응답("성남치과 추천", 2026-06, web_search, 소비자 앱). 인용 URL의 `?utm_source=chatgpt.com` 태그가 곧 실제 노출 증거.
- **통제:** 같은 질의·같은 지역(성남) → 위치·의도 교란 최소화. 즉 6곳 모두 동일 질의의 동등 후보.
- **예측:** 각 치과 홈페이지를 `lib/audit.js`(score-cli)로 채점. 무료·키 없음.
- **표본:** 6곳(실제 노출 5 + 미노출 1). 소표본·단일질의·단일엔진 = v0.1 한계(아래 위협 참조).

## 진단 — 점수가 실패한 3가지와 왜

1. **역상관.** 뜬 5곳 점수(60·15~45·modoo·측정불가·측정불가) vs 안 뜬 1곳(63=최고). "점수↑ → 노출↑" 가설을 데이터가 정면 반박.
2. **커버리지 붕괴(측정불가 2/5).** 실제 엔진은 JS를 **렌더**하고 다중 소스(디렉터리·플레이스)를 참조한다. 우리는 raw HTML 1장을 SSRF-safe로 한 번 가져온다. → 인증서 만료(나의특별한)·TLS 끊김(서울퍼펙트) 사이트를 엔진은 인용하는데 우리는 0점도 못 매김.
3. **재현성 없음.** JS-shell 간헐 응답 + utm 파라미터 분기로 같은 URL이 회차마다 다른 점수. "기준"이 되려면 재현성이 전제인데 깨짐.

## 실제 노출 동인 (실측에서 관측됨)

- **디렉터리 다중 등재** — 뜬 치과 전부 goodoc·modoodoc·ddocdoc·hidoc·daangn·doctornow·miclick에 깔려 있음. 웃자는 자기 사이트가 아니라 **doctornow로 인용**.
- **전문의 자격(엔티티 사실)** — GPT가 명시 인용: 턱사랑=구강악안면외과 전문의, 웃자=교정과 전문의, 서울퍼펙트=보철과 전문의.
- **의도 슬롯 매칭** — 사랑니/턱관절·야간/주말·보철상담으로 각 치과를 배치.

→ 셋 다 페이지 HTML 위생이 아니라 **존재·엔티티·의도**다. 그리고 셋 다 예측할 필요 없이 **실측으로 직접 관측**된다.

## 권고

1. **실측을 1급 지표로.** 점수는 "페이지 추출 위생(필요조건, 노출예측 아님)"으로 강등·재라벨.
2. **fetch 견고화** — 인증서 만료·TLS 끊김·modoo/SPA → `status:'unmeasurable'`(0 위장 금지·사유 표기).
3. **재현성 고정** — JS-shell 판정 안정화, 렌더 후 재측정 또는 PSI 렌더 점수 활용.
4. **확대 검증** — 다도시 × 다의도 × 균형표본(뜬/안뜬 모두) × 다엔진(+Perplexity). API 또는 수동 실측으로 N 확대.

## 위협 / 한계 (반허위)

- **단일 질의·소표본(n=6)·단일 엔진(ChatGPT 소비자앱).** 일반화 금지. 이 문서는 v0.1 = "점수가 예측한다"는 가설의 **반증 1건**이지, 동인의 정량 모델이 아님.
- 소비자 앱 ≠ API(결과·시점 변동). "안 뜸"은 해당 질의·시점 한정(영구 아님).
- 다음 버전(v0.2): 균형표본 + 다엔진 + 반복측정으로 동인을 정량화.
