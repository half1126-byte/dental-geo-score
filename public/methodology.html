치과 GEO 인용 점수 산정 방법론

점수의 모든 항목은 측정 가능하고 재현 가능한 근거로만 만듭니다. 추정치를 사실로 쓰지 않습니다.

두 지표의 구분 (중요)

① 준비도 점수(0~100) — 이 페이지가 정의하는 점수. 페이지 구조 신호만으로 계산하는 결정론적 값입니다. 같은 URL·같은 방법론 버전·같은 렌더 결과면 같은 점수가 나옵니다(재현 가능).

② 실측 인용(관측) — ChatGPT·Perplexity에 실제로 질문해 인용 여부를 측정한 값. 생성형 AI는 비결정론적이므로, 이는 점수가 아니라 측정 시점의 관측 + 신뢰구간으로 제시합니다(N회 반복·증거 동봉). ①은 ②의 필요조건(추출 위생)일 뿐, ②를 예측하지 않습니다 — 자사 검증(v0.1)에서 준비도 점수와 실제 인용은 상관이 없었습니다(검증 리포트 참조). 점수가 높아도 안 뜨고, 낮아도 뜰 수 있습니다.

준비도 점수 — 9개 신호와 배점

두 축으로 나눠 봅니다. 축A 기술 준비도(50)는 "AI 크롤러가 읽을 수 있는가", 축B 콘텐츠 인용성(50)은 "인용할 가치가 있는가"입니다.

수치의 해석 — "30~40%"가 뜻하지 않는 것

KDD 2024의 상위 3기법 수치는 업계에서 자주 인용되지만, 그대로 성과 약속으로 옮기면 틀립니다. 정확히는 이렇습니다.

  • 이미 후보에 들어온 뒤의 재배분입니다. 해당 실험은 5개 문서가 컨텍스트에 올라온 상태에서 그 안의 인용 지분이 어떻게 나뉘는지를 측정했습니다. 검색 후보에 못 들어간 페이지에는 적용되지 않습니다.
  • 클릭·내원·매출은 측정되지 않았습니다. 측정된 것은 답변 텍스트 안의 노출 지분입니다.
  • 순위에 따라 부호가 뒤집힙니다. 출처 명시는 검색 5위권에서 +115.1%였지만 이미 1위인 사이트에서는 −30.3%였습니다. 같은 작업이 위치에 따라 반대로 작동합니다.
  • 안정적인 인과효과는 아직 확립되지 않았습니다. GEO 연구 45편을 검토한 서베이(arXiv:2607.14035)는 "안정적이고 종단적이며 플랫폼을 가로지르는 인과효과를 보인 기법은 없다"고 결론냅니다.
  • 본문만 손대면 역효과일 수 있습니다. SAGEO Arena는 본문만 최적화했을 때 검색 단계 Hit Rate가 −9%였다고 보고합니다. 축A(읽히는 조건)가 먼저인 이유입니다.
  • 규모에 따라 결과가 크게 다릅니다. 브랜드 규모별 측정(arXiv:2606.20065)에서 대형 브랜드 가시성은 73%였지만 소규모·니치는 11%였습니다. 개별 의원에 대형 브랜드 기준의 기대치를 적용하면 안 됩니다.

한국어 대상 GEO 연구는 위 서베이 45편 안에 한 건도 없습니다. 국내 적용의 외적 타당성은 검증되지 않았으며, 자체 실측 축적으로만 확인할 수 있습니다.

등급 산정

75점 이상 우수 / 50점 이상 보통 / 30점 이상 개선 여지 큼 / 그 미만 초기 단계.

단, 아래 셋 중 하나에 해당하면 총점과 무관하게 '우수' 등급을 보류하고 '보통'까지만 부여합니다. 점수 자체는 그대로 두고 등급 라벨만 조정합니다.

  • 인용 경로 크롤러 차단 — 답변에 출처로 실리는 봇이 막힌 경우입니다. 인용 후보에서 아예 제외되므로 '우수'를 붙이는 것이 정확하지 않습니다. 학습 전용 봇(GPTBot·CCBot 등)만 막은 것은 여기에 해당하지 않습니다.
  • 인용 근거 0점 — 출처·인용구·통계가 하나도 없다는 뜻입니다. 위 연구가 실측한 상위 3개 기법이 전부 비어 있는 페이지를 '우수'라고 부르면 이 방법론과 모순됩니다.
  • 측정 제한(JS 렌더) — 본문을 정적으로 읽지 못한 결과는 하한선입니다. 읽지 못한 페이지에 '우수'를 붙이지 않습니다.

이 게이트는 v0.3에서 도입하고 v0.4에서 크롤러 판정을 정정했습니다(학습 전용 봇만 막은 사이트는 더 이상 게이트에 걸리지 않습니다). 도입 전 기준으로 '우수'였던 페이지 상당수가 '보통'으로 바뀝니다 — 대부분 인용 근거가 0점이기 때문입니다. 등급을 후하게 주는 것보다 무엇이 비어 있는지 정확히 알려드리는 쪽을 택했습니다.

재현성

  • 준비도 점수는 동일 입력 + 동일 방법론 버전 + 동일 렌더 결과에서 결정론적으로 동일합니다.
  • 모든 결과에 methodologyVersion·measuredAt·renderMode·domain을 동봉합니다.
  • JS 렌더(SPA) 사이트는 일부 신호를 읽지 못하므로 "측정 제한"으로 정직하게 표기합니다(0점 위장 금지).

한계 (정직 고지)

  • 준비도 점수는 인용의 필요조건(추출 위생)이며 노출을 예측하지 않습니다 — 자사 검증에서 점수와 실제 인용은 무상관이었습니다. 실제 인용 여부는 ②실측으로만 확인합니다.
  • 실측 인용은 API 기준 관측으로, 소비자 앱(chatgpt.com 등)의 결과와 다를 수 있습니다.
  • 네이버 AI 브리핑은 공개 API가 없어 자동 측정 대상이 아니며, 별도 준비도 체크리스트로 다룹니다.

변경 이력

  • v0.4 (2026-08-06) — 후속 연구를 반영해 배점을 재조정하고 크롤러 판정을 다시 만들었습니다.
    • 비급여 진료비 안내(5점) 신설 · 신선도 5→10 — 25.2만회 통제 실험(arXiv:2605.25517)에서 '가격 미기재'와 '오래된 타임스탬프'가 6개 모델 공통의 인용 탈락 요인으로 확인됐습니다.
    • Answer-first 15→10 — 포맷팅 단독 효과의 근거가 약하다는 후속 연구(Q&A 포맷 −5.74%, 서베이 45편)를 반영했습니다.
    • 구조화 데이터 15→10 — Google이 "구조화 데이터는 생성형 AI 검색에 필수가 아니다"라고 명시했고, FAQ 리치리절트는 2026년 5월 노출이 중단됐습니다. 그에 따라 FAQPage가 두 항목에서 중복 계상되던 것을 바로잡고 배점을 낮췄습니다.
    • robots.txt 판정 재작성 — RFC 9309(와일드카드·최장일치·정확 토큰 일치)를 구현하고, 봇을 인용 경로 / 사용자 요청 / 학습 / 폐기 4종으로 분류했습니다. 이전에는 무관한 User-agent: bot 그룹이 AI 봇 6종 차단으로 오판됐고, Disallow: /*는 차단으로 잡히지 않았으며, 학습 전용 봇만 막은 사이트가 인용 경로를 막은 사이트와 동일하게 감점됐습니다.
    • 권위 sameAs 신호가 채점기에 전달되지 않던 배선 오류를 수정했습니다(해당 배점이 실제로 지급된 적이 없었습니다).
  • v0.3 (2026-08-06) — '인용 근거' 항목을 독립 신호로 승격(15점). v0.2까지 이 신호는 Answer-first 항목 안에 합계 6점으로 묻혀 있어 리포트에 보이지 않았습니다. Aggarwal et al.(KDD 2024)이 쿼리 1만 건으로 실측한 상위 3개 기법이 출처 명시·전문가 인용구·통계 수치였고, 그중 출처 명시가 단일 최대 효과(검색 5위권 기준)였기에 별도 항목으로 분리하고 배점을 올렸습니다. 재원은 구조화 데이터 20→15, 신선도 10→5, Answer-first 20→15에서 조달했습니다 — 세 항목 모두 해당 논문이 직접 실측한 대상이 아니기 때문입니다. 함께 등급 게이트(크롤러 차단 시 '우수' 불가)를 도입했습니다.
  • v0.2 — 두 진단 축(기술 준비도 / 콘텐츠 인용성) 분리.
  • v0.1 (2026-06-22) — 최초 공개. 7개 신호·배점 정의.
