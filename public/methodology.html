치과 GEO 인용 점수 산정 방법론

점수의 모든 항목은 측정 가능하고 재현 가능한 근거로만 만듭니다. 추정치를 사실로 쓰지 않습니다.

두 지표의 구분 (중요)

① 준비도 점수(0~100) — 이 페이지가 정의하는 점수. 페이지 구조 신호만으로 계산하는 결정론적 값입니다. 같은 URL·같은 방법론 버전·같은 렌더 결과면 같은 점수가 나옵니다(재현 가능).

② 실측 인용(관측) — ChatGPT·Perplexity에 실제로 질문해 인용 여부를 측정한 값. 생성형 AI는 비결정론적이므로, 이는 점수가 아니라 측정 시점의 관측 + 신뢰구간으로 제시합니다(N회 반복·증거 동봉). 준비도 점수는 ②의 가능성을 높이는 예측치입니다.

재현성

  • 준비도 점수는 동일 입력 + 동일 방법론 버전 + 동일 렌더 결과에서 결정론적으로 동일합니다.
  • 모든 결과에 methodologyVersion·measuredAt·renderMode·domain을 동봉합니다.
  • JS 렌더(SPA) 사이트는 일부 신호를 읽지 못하므로 "측정 제한"으로 정직하게 표기합니다(0점 위장 금지).

한계 (정직 고지)

  • 준비도 점수는 인용 가능성의 예측이며, 실제 인용을 보장하지 않습니다.
  • 실측 인용은 API 기준 관측으로, 소비자 앱(chatgpt.com 등)의 결과와 다를 수 있습니다.
  • 네이버 AI 브리핑은 공개 API가 없어 자동 측정 대상이 아니며, 별도 준비도 체크리스트로 다룹니다.
